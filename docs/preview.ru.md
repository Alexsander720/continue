# Запуск витрины Continue?

[English](preview.md) · [Українська](preview.uk.md) · **Русский**

Текущий клон — статичная презентация в браузере: 20 снимков сохранений и виды Дека / ПК.
Он не подключается к Steam, не читает твои сейвы, не устанавливает плагин и не запускает игры.

## Запуск

Нужны Git-доступ к репозиторию, Python 3 и современный браузер. Репозиторий пока приватный,
поэтому для клонирования нужен аккаунт с доступом. Зависимости pip/npm и API-ключи не требуются.

```sh
git clone https://github.com/Alexsander720/continue.git
cd continue
python tools/preview.py
```

Открой **http://127.0.0.1:8811/**. На Windows также работает `py -3 tools/preview.py`,
на macOS/Linux — `python3 tools/preview.py`. Остановка: **Ctrl+C** в этом терминале.
Сервер доступен только с текущего компьютера.

Если порт занят: `python tools/preview.py --port 8813`, затем **http://127.0.0.1:8813/**.
Скрипт можно запускать из любой папки, указав его абсолютный путь.

## Управление

| Элемент | Результат |
|---|---|
| Обложки / назад-вперёд | Выбор снимка сохранения |
| Дека / ПК | Смена раскладки устройства |
| EN / UK / RU | Язык интерфейса; недоступные названия остаются на подписанном языке источника |
| Увеличение | То же демо в диалоге; Escape закрывает и возвращает фокус |
| Пауза фона | Остановка движущихся фонов |
| Поиск и фильтры каталога | Поиск игры; три перепроверяемых парсера показывают только подтверждённую часть |
| Тур | MP4 на 40 секунд на текущем языке интерфейса |
| «Играть» / «Продолжить» | Демонстрационный отклик; игра не запускается |

В браузере предусмотрена раскладка контроллера, но поддержку браузера/геймпада и физическое устройство нужно
проверять отдельно. Доступны клавиатура и сенсорное управление. Настройка уменьшения анимации учитывается там, где поддерживается.

## Медиа и неполадки

| Что видно | Причина / действие |
|---|---|
| Нет кнопки музыки | Темы намеренно исключены из Git; без локального файла кнопка скрыта |
| Другой сервер не даёт перематывать тур | Используй `tools/preview.py`: он поддерживает диапазоны HTTP и маршруты к `docs/img/` |
| Названия остаются русскими/английскими | Подписанный язык подтверждённого источника; перевод интерфейса не придумывает строки игры |
| У ENSLAVED нет демо | Парсер перепроверяется; подтверждённый пример не добавлен |
| Страница не открывается | Терминал сервера должен работать; проверь напечатанный URL и порт |
| Изменения не видны | Обнови страницу; проверь консоль/сеть на отсутствующий ресурс |

Туры хранятся одной копией в `docs/img/tour-<lang>.mp4`. Сервер направляет `/media/tour-<lang>.mp4`
к ней без копирования. Workflow Pages копирует видео в артефакт публикации.
Личные сейвы, таблицы имён и музыка тем не входят в клон Git.

## Разработка и публикация

Меняй `site/index.html`, `site/style.css`, `site/app.js`, `site/data.js` или `site/store.js` и обновляй браузер.
Сборки нет. Проверяй языки, раскладку, фокус и источники; подробнее — [CONTRIBUTING](../CONTRIBUTING.md).

Workflow Pages публикует только из публичного репозитория. Изменение приватности, включение Pages и проверенная
ссылка на сайт — отдельные решения владельца. Локальный запуск ничего не публикует.
