# Quick install: Steam Deck & Windows PC

**English** · [Українська](quick-install.uk.md) · [Русский](quick-install.ru.md)

### Steam Deck (4 steps)

1. Download [`continue-deck-0.1.4.zip`](https://github.com/Alexsander720/continue/releases/download/v0.1.4/continue-deck-0.1.4.zip) from [Release v0.1.4](https://github.com/Alexsander720/continue/releases/latest) (do not unpack).
2. Press `…` on your Steam Deck and navigate to **Decky → Settings → Developer → Install from URL/ZIP**.
3. Choose the downloaded ZIP file and confirm installation.
4. Open any supported game page in your Steam library — Continue? is ready!

Full Steam Deck guide: [install-deck.md](install-deck.md).

### Windows PC / Big Picture (5 steps)

1. Ensure Python 3.10+ is installed, then download [`continue-pc-0.1.4-r19.zip`](https://github.com/Alexsander720/continue/releases/download/v0.1.4/continue-pc-0.1.4-r19.zip) and its `.sha256` from [Release v0.1.4](https://github.com/Alexsander720/continue/releases/latest).
2. Unpack the ZIP archive into an ordinary local folder on your computer.
3. Close running games and double-click `Continue\setup.cmd` (or `setup.cmd`).
4. Agree to enable Steam's local debugging port (`127.0.0.1:8080`) and allow Steam to restart.
5. Launch Steam in Big Picture mode and open any supported game page!

Full PC guide: [install-pc.md](install-pc.md).
