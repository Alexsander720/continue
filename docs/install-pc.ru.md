# Установка на Windows / Big Picture

[English](install-pc.md) · [Українська](install-pc.uk.md) · **Русский**

Эта инструкция написана для пакета Windows Steam Big Picture (`continue-pc-0.1.4-r19.zip`), опубликованного в [релизе v0.1.4](https://github.com/Alexsander720/continue/releases/latest).
Исходный код службы и установщика включён в репозиторий в папке `pc/`. Пакет прошёл проверки в настоящем Steam на Windows 11 x64 на компьютере владельца и в автотестах; приёмка на чистых установках Windows 10, ARM64 и с различными антивирусами продолжается.
Установщик и служба проверены во временных профилях Windows с изолированным тестовым Steam/CDP. 13.10.2026 в настоящем Steam Big Picture на Windows 11 x64 также проверены установка, ремонт, карточка игры, вкладки библиотеки, настройки, отказ от установки и удаление. На этом ПК уже были Python и включённая отладка Steam. Чистая учётная запись без Python, Windows 10 и ARM64 — экспериментально; использование физического контроллера ещё не проверено. Относитесь к пакету как к альфа-версии и закрывайте игры перед перезапуском Steam.

Требования: Windows 10 или 11, Steam в текущей учётной записи Windows и режим Big Picture. Права администратора
не запрашиваются и не нужны. Continue? использует только стандартную библиотеку Python. Если Python 3.10+ с
`pythonw.exe` не найден, установщик скачивает закреплённую встроенную сборку Python с python.org, проверяет
официальный SHA-256 и подпись издателя и кладёт её только в профиль пользователя. PATH и системный реестр не меняются.

## Установка: двойной клик, согласие, перезапуск Steam

1. Скачай релизный архив `continue-pc-0.1.4-r19.zip` и соседний `continue-pc-0.1.4-r19.zip.sha256` из [последнего релиза](https://github.com/Alexsander720/continue/releases/latest).
   Проверь контрольную сумму в PowerShell одной строкой:
   ```powershell
   (Get-FileHash .\continue-pc-0.1.4-r19.zip).Hash -eq ((Get-Content .\continue-pc-0.1.4-r19.zip.sha256) -split '\s+')[0]
   ```
   Если команда вернула `True`, полностью распакуй ZIP в обычную локальную папку.
   Также можно собрать локальный тестовый кандидат из исходников репозитория:
   ```bash
   python tools/build_pc_zip.py
   # или с явным указанием версии:
   python tools/build_pc_zip.py 0.1.4
   ```
   Команда создаёт `dist/continue-pc-<версия>.zip` и `dist/continue-pc-<версия>.zip.sha256`.
2. Дважды нажми `Continue\setup.cmd` (или `Continue\pc\setup.cmd`). Windows может предупредить, потому что это
   читаемые `.cmd`, `.ps1`, `.py` и JavaScript, а не подписанный EXE-установщик. При желании сначала просмотри код;
   права администратора не выдавай. `-ExecutionPolicy Bypass` применяется только к локальному скрипту установки.
3. Прочитай предупреждение об отладочном порте и соглашайся только осознанно. Continue? создаёт пустой файл
   `<Steam>\.cef-enable-remote-debugging`. При следующем запуске Steam он включает интерфейс отладки UI на
   `127.0.0.1:8080`. С другого компьютера порт напрямую недоступен, но **любой процесс в твоей учётной записи на
   этом ПК сможет обращаться к интерфейсу Steam, пока флаг включён**. Это главный риск версии для ПК.
4. Дождись копирования приложения и регистрации пользовательской задачи. Когда установщик предложит перезапустить
   Steam, сначала закрой игры. Только после согласия установщик просит Steam штатно завершиться; принудительного
   убийства процесса нет. Можно ответить «нет» и позже перезапустить Steam самостоятельно.
5. Открой Big Picture и страницу поддерживаемой игры. Если Steam закрыт, перезапускается или ещё не открыл порт,
   служба ждёт и подключается заново. Отсутствие сейва или сети даёт пустой/статичный fallback и не меняет игру.

Повторный запуск — это ремонт: настройки и данные сохраняются, приложение заменяется атомарно, принадлежность флага
сохраняется, задача чинится. `install.json` хранит версию, пути, выбранный Python, задачу и признак того, что флаг
отладки создал именно Continue?.

## Настройки в Big Picture

Открой **Continue?** в главном меню Steam либо **…** на странице игры. Здесь разделы «Библиотека», «Карточка игры», «Фоны», «Музыка», «Оформление» и «Подключения». Вкладки Continue? по умолчанию выключены; при наличии TabMaster управление остаётся у него.

Музыка включается один раз для библиотеки после явного согласия. Фоны и музыка готовятся только для открываемых игр. Детали сейва можно скрывать глобально и отдельно для игры. Ключ SteamGridDB необязателен и хранится только в твоём профиле.

[Первое использование: музыка, качество и место, карточки, картинки и язык](pc-first-start.ru.md). Кнопки, значки контроллера и стиль карточки сохраняют оформление исходной Big Picture-сборки; дополнительные темы находятся в «Оформление» → «Больше настроек оформления».

## Что меняется на ПК

| Часть | Точное поведение |
|---|---|
| Флаг Steam | Пустой `<Steam>\.cef-enable-remote-debugging`; удаляется только если был создан Continue? и остался пустым |
| Порт Steam | После перезапуска сам Steam открывает `127.0.0.1:8080`; Continue? этот порт не слушает |
| Медиапорт Continue? | Служба слушает только `127.0.0.1:8793` и отдаёт разрешённые типы только из `%LOCALAPPDATA%\Continue\data`; есть Range и строгие проверки Host, заголовков, путей и ссылок |
| Задача Планировщика | Пользовательская `ContinueBigPicture`: при входе и каждые 10 минут, `IgnoreNew`, ограниченные права, записанный `pythonw.exe` без окна консоли |
| Приложение | `%LOCALAPPDATA%\Continue\app` |
| Настройки, данные, логи | `%LOCALAPPDATA%\Continue\settings.json`, `data`, ротируемый `logs\bp.log` |
| Манифест установки | `%LOCALAPPDATA%\Continue\install.json` |
| Необязательный Python | `%LOCALAPPDATA%\Continue\python`, только если подходящий Python не найден |

Публичная сборка содержит самостоятельные окна картинок, музыки и тем с прежним оформлением. Личный хаб, SSH на Деку и ключ разработчика в пакет не входят. Карточки читаются локально теми же публичными `ddsaves`, что на
Деке. Описание и метаданные медиа может дать Steam Store; ошибки HLTB, сети и медиа не фатальны. `ffmpeg`/`ffprobe`
появляются только вместе с необязательными инструментами обработки: загружаются после явного согласия в профиль
Continue? и проверяются по контрольной сумме; в систему целиком они не устанавливаются.

### Сторонние программы и медиа

Трейлеры YouTube и музыка тем загружаются только после явного согласия, локально на этом ПК. Проект не поставляет
сторонние аудио и видео, а пользователь сам отвечает за соблюдение условий сервисов и авторских прав.
Вспомогательные программы (закреплённый Python с python.org, yt-dlp, Node и FFmpeg) — стороннее ПО под своими
лицензиями; загружаются только с согласия в профиль Continue?, и каждый архив проверяется по контрольной сумме
перед использованием.

## Статус и журнал

Открой PowerShell в папке `pc` распакованного или установленного приложения:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\status.ps1
```

Команда только читает состояние: версия, точный записанный процесс службы, принадлежность задачи, Steam и флаг,
ответы портов 8080/8793 (Steam, Continue?, чужая программа), размер кэша, последний лог и понятная подсказка.
Ротируемый журнал находится в `%LOCALAPPDATA%\Continue\logs` и работает под `pythonw.exe`, где stdout отсутствует.

## Обновления

Публичная установка проверяет GitHub Releases не чаще раза в сутки. Принимается только более новый стабильный
`continue-pc-<версия>.zip` с точным `.sha256`: проверяются HTTPS-хосты, размеры, пути ZIP, SHA-256 и публичный
`RELEASE.json`. Отдельный helper ждёт завершения текущей службы, распаковывает релиз рядом, атомарно меняет папку,
запускает новую службу и ждёт свежую health-запись с версией и одноразовым nonce. При неудачном старте возвращается
и запускается прежняя версия. Рабочая копия без `RELEASE.json` не обновляется.

Публичный альфа-пакет для ПК опубликован в GitHub Releases начиная с v0.1.4 (`continue-pc-0.1.4-r19.zip`). Служба автоматического обновления будет проверять наличие последующих стабильных версий в релизах GitHub.

## Удаление

Запускай установленный скрипт, чтобы он использовал записанную принадлежность объектов:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "$env:LOCALAPPDATA\Continue\app\pc\uninstall.ps1"
```

Он останавливает только записанную службу Continue?, снимает только совпадающую задачу `ContinueBigPicture` и
удаляет отладочный флаг Steam только тогда, когда его создал Continue? и файл всё ещё пуст. Чужой или изменённый
флаг сохраняется. По умолчанию удаление предлагает стереть данные/кэш, логи и настройки и показывает размер кэша;
можно сохранить их. Копия приложения и принадлежащий Continue? встроенный Python удаляются. Уже внедрённый JavaScript
живёт в памяти Steam до перезапуска — закрой игры и согласись на штатный перезапуск либо сделай его вручную.

## Неполадки

| Симптом | Причина | Что сделать |
|---|---|---|
| «Steam was not found» | Steam не установлен для этой учётной записи или нет пути в HKCU | Один раз установи/запусти Steam в этой учётной записи и повтори setup |
| Флаг есть, порт 8080 закрыт | Steam не перезапускали после создания флага | Закрой игры, полностью выйди из Steam и запусти снова |
| На 8080 «another program» | Порт занят не Steam или Steam вернул неизвестную цель | Закрой конфликтующую программу, перезапусти Steam и снова проверь status |
| На 8793 «another program» | Медиапорт Continue? занят другой службой | Определи и закрой её, затем повтори setup; не убивай неизвестные процессы вслепую |
| Нет службы/задачи | Задачу удалили, путь изменился, Python попал в карантин или установка оборвалась | Проверь Защиту Windows и последний лог, затем запусти `setup.cmd` для ремонта |
| В Big Picture нет панели | Steam не загрузил флаг, SharedJSContext ещё стартует или сборка Steam изменилась | Немного подожди, проверь status/log, перезапусти Steam; приложи версию Steam к отчёту |
| Панель есть, фактов сейва нет | Игра/слот не поддерживается, путь другой или сейва нет | Сверь список читателей; Continue? не додумывает факты и не пишет сейвы |
| Нет описания/трейлера/HLTB | Нет сети, сбой Store, настройки согласия, мало места или нет необязательного `ffmpeg` | Статичная карточка должна работать; попробуй позже и проверь статус медиа |
| Ошибка Python/hash/signature | Перехват сети, неполная загрузка или карантин антивируса | Не обходи проверку; повтори в обычной сети и проверь Защиту Windows |
| SmartScreen/антивирус предупреждает | Скрипты альфы не подписаны; встроенный Python подписан python.org | Просмотри открытый код и checksum. Не отключай защиту целиком и не запускай от администратора |
| Uninstall говорит о чужой задаче | Задача с тем же именем не совпадает с `install.json` | Сохрани её; восстанавливай манифест или удаляй постороннюю задачу только после идентификации |
