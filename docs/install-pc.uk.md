# Встановлення на Windows / Big Picture

[English](install-pc.md) · **Українська** · [Русский](install-pc.ru.md)

Ця інструкція призначена для пакета Windows Steam Big Picture (`continue-pc-0.1.4-r19.zip`), опублікованого в [релізі v0.1.4](https://github.com/Alexsander720/continue/releases/latest).
Вихідний код служби та встановлювача включено до репозиторію в папці `pc/`. Пакет пройшов перевірки у справжньому Steam на Windows 11 x64 на комп'ютері власника та в автотестах; приймання на чистих інсталяціях Windows 10, ARM64 та з різними антивірусами триває.
Встановлювач і службу перевірено в тимчасових профілях Windows з ізольованим тестовим Steam/CDP. 13.10.2026 у справжньому Steam Big Picture на Windows 11 x64 також перевірено встановлення, відновлення, картку гри, вкладки бібліотеки, налаштування, відмову від встановлення та видалення. На цьому ПК уже були Python і ввімкнене налагодження Steam. Чистий обліковий запис без Python, Windows 10 і ARM64 — експериментально; використання фізичного контролера ще не перевірено. Ставтеся до пакета як до альфа-версії та закривайте ігри перед перезапуском Steam.

Вимоги: Windows 10 або 11, Steam у поточному обліковому записі Windows і режим Big Picture. Права адміністратора
не запитуються й не потрібні. Continue? використовує лише стандартну бібліотеку Python. Якщо Python 3.10+ із
`pythonw.exe` не знайдено, встановлювач завантажує закріплену вбудовану збірку Python з python.org, перевіряє
офіційний SHA-256 і підпис видавця та кладе її лише до профілю користувача. PATH і системний реєстр не змінюються.

## Встановлення: подвійний клік, згода, перезапуск Steam

1. Завантаж релізний архів `continue-pc-0.1.4-r19.zip` і сусідній `continue-pc-0.1.4-r19.zip.sha256` з [останнього релізу](https://github.com/Alexsander720/continue/releases/latest).
   Перевір контрольну суму в PowerShell одним рядком:
   ```powershell
   (Get-FileHash .\continue-pc-0.1.4-r19.zip).Hash -eq ((Get-Content .\continue-pc-0.1.4-r19.zip.sha256) -split '\s+')[0]
   ```
   Якщо команда повернула `True`, повністю розпакуй ZIP у звичайну локальну папку.
   Також можна зібрати локальний тестовий кандидат із вихідних файлів репозиторію:
   ```bash
   python tools/build_pc_zip.py
   # або з явною версією:
   python tools/build_pc_zip.py 0.1.4
   ```
   Команда створює `dist/continue-pc-<версія>.zip` і `dist/continue-pc-<версія>.zip.sha256`.
2. Двічі натисни `Continue\setup.cmd` (або `Continue\pc\setup.cmd`). Windows може попередити, бо це читабельні
   `.cmd`, `.ps1`, `.py` і JavaScript, а не підписаний EXE-встановлювач. За бажанням спершу переглянь код; прав
   адміністратора не надавай. `-ExecutionPolicy Bypass` застосовується лише до локального скрипту встановлення.
3. Прочитай попередження про налагоджувальний порт і погоджуйся лише свідомо. Continue? створює порожній файл
   `<Steam>\.cef-enable-remote-debugging`. Під час наступного запуску Steam він вмикає інтерфейс налагодження UI на
   `127.0.0.1:8080`. З іншого комп'ютера порт безпосередньо недоступний, але **будь-який процес у твоєму обліковому
   записі на цьому ПК зможе звертатися до інтерфейсу Steam, доки прапорець увімкнений**. Це головний ризик PC-версії.
4. Дочекайся копіювання застосунку й реєстрації користувацького завдання. Коли встановлювач запропонує перезапустити
   Steam, спершу закрий ігри. Лише після згоди він просить Steam штатно завершитися; примусового завершення процесу
   немає. Можна відповісти «ні» й перезапустити Steam самостійно пізніше.
5. Відкрий Big Picture і сторінку підтримуваної гри. Якщо Steam закритий, перезапускається або ще не відкрив порт,
   служба чекає та під'єднується знову. Відсутність сейва або мережі дає порожній/статичний fallback і не змінює гру.

Повторний запуск — це ремонт: налаштування й дані зберігаються, застосунок замінюється атомарно, належність прапорця
зберігається, завдання виправляється. `install.json` містить версію, шляхи, вибраний Python, завдання та ознаку того,
що прапорець налагодження створив саме Continue?.

## Налаштування в Big Picture

Відкрий **Continue?** у головному меню Steam або **…** на сторінці гри. Тут розділи «Бібліотека», «Картка гри», «Тло», «Музика», «Оформлення» та «Підключення». Вкладки Continue? спочатку вимкнені; за наявності TabMaster керування залишається за ним.

Музика вмикається один раз для бібліотеки після явного дозволу. Тло й музика готуються лише для відкритих ігор. Деталі збереження можна приховувати глобально й окремо для гри. Ключ SteamGridDB необов’язковий і залишається у твоєму профілі.

[Перше використання: музика, якість і місце, картки, зображення та мова](pc-first-start.uk.md). Кнопки, значки контролера й стиль картки зберігають оформлення початкової Big Picture-збірки; додаткові теми — в «Оформлення» → «Більше налаштувань оформлення».

## Що змінюється на ПК

| Частина | Точна поведінка |
|---|---|
| Прапорець Steam | Порожній `<Steam>\.cef-enable-remote-debugging`; видаляється лише якщо його створив Continue? і він лишився порожнім |
| Порт Steam | Після перезапуску сам Steam відкриває `127.0.0.1:8080`; Continue? цей порт не слухає |
| Медіапорт Continue? | Служба слухає лише `127.0.0.1:8793` і віддає дозволені типи лише з `%LOCALAPPDATA%\Continue\data`; є Range і суворі перевірки Host, заголовків, шляхів та посилань |
| Завдання Планувальника | Користувацьке `ContinueBigPicture`: під час входу й кожні 10 хвилин, `IgnoreNew`, обмежені права, записаний `pythonw.exe` без вікна консолі |
| Застосунок | `%LOCALAPPDATA%\Continue\app` |
| Налаштування, дані, журнали | `%LOCALAPPDATA%\Continue\settings.json`, `data`, ротований `logs\bp.log` |
| Маніфест встановлення | `%LOCALAPPDATA%\Continue\install.json` |
| Необов'язковий Python | `%LOCALAPPDATA%\Continue\python`, лише коли придатний Python не знайдено |

Публічна збірка містить самостійні вікна зображень, музики й тем із початковим оформленням. Особистий хаб, SSH на Дек та ключ розробника до пакета не входять. Картки читаються локально тими самими публічними
`ddsaves`, що на Деку. Опис і метадані медіа може надати Steam Store; помилки HLTB, мережі й медіа не фатальні.
`ffmpeg`/`ffprobe` з'являються лише разом із необов'язковими інструментами обробки: завантажуються після явної згоди
до профілю Continue? і перевіряються за контрольною сумою; у систему загалом вони не встановлюються.

### Сторонні програми й медіа

Трейлери YouTube й музика тем завантажуються лише після явної згоди, локально на цьому ПК. Проєкт не постачає
сторонні аудіо та відео, а користувач сам відповідає за дотримання умов сервісів і авторських прав. Допоміжні
програми (закріплений Python з python.org, yt-dlp, Node й FFmpeg) — стороннє ПЗ під власними ліцензіями;
завантажуються лише за згодою до профілю Continue?, і кожен архів перевіряється за контрольною сумою
перед використанням.

## Стан і журнал

Відкрий PowerShell у папці `pc` розпакованого або встановленого застосунку:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\status.ps1
```

Команда лише читає стан: версія, точний записаний процес служби, належність завдання, Steam і прапорець, відповіді
портів 8080/8793 (Steam, Continue?, інша програма), розмір кешу, останній журнал і зрозуміла підказка. Ротований
журнал лежить у `%LOCALAPPDATA%\Continue\logs` і працює під `pythonw.exe`, де stdout відсутній.

## Оновлення

Публічне встановлення перевіряє GitHub Releases не частіше одного разу на добу. Приймається лише новіший стабільний
`continue-pc-<версія>.zip` із точним `.sha256`: перевіряються HTTPS-хости, розміри, шляхи ZIP, SHA-256 і публічний
`RELEASE.json`. Окремий helper чекає завершення поточної служби, розпаковує реліз поруч, атомарно міняє папку,
запускає нову службу й чекає свіжий health-запис із версією та одноразовим nonce. Якщо запуск невдалий, попередня
версія повертається і запускається. Робоча копія без `RELEASE.json` не оновлюється.

Публічний альфа-пакет для ПК опубліковано в GitHub Releases починаючи з v0.1.4 (`continue-pc-0.1.4-r19.zip`). Служба автоматичного оновлення перевірятиме наявність наступних стабільних версій у релізах GitHub.

## Видалення

Запускай встановлений скрипт, щоб він використав записану належність об'єктів:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "$env:LOCALAPPDATA\Continue\app\pc\uninstall.ps1"
```

Він зупиняє лише записану службу Continue?, прибирає лише відповідне завдання `ContinueBigPicture` і видаляє
налагоджувальний прапорець Steam лише тоді, коли його створив Continue? і файл досі порожній. Чужий або змінений
прапорець зберігається. Типово видалення пропонує стерти дані/кеш, журнали й налаштування та показує розмір кешу;
їх можна залишити. Копія застосунку й належний Continue? вбудований Python видаляються. Уже ін'єктований JavaScript
лишається в пам'яті Steam до перезапуску — закрий ігри та погодься на штатний перезапуск або зроби його вручну.

## Несправності

| Симптом | Причина | Що зробити |
|---|---|---|
| «Steam was not found» | Steam не встановлено для цього облікового запису або немає шляху в HKCU | Один раз встанови/запусти Steam у цьому обліковому записі й повтори setup |
| Прапорець є, порт 8080 закритий | Steam не перезапускали після створення прапорця | Закрий ігри, повністю вийди зі Steam і запусти знову |
| На 8080 «another program» | Порт зайнятий не Steam або Steam повернув невідому ціль | Закрий конфліктну програму, перезапусти Steam і знову перевір status |
| На 8793 «another program» | Медіапорт Continue? зайнятий іншою службою | Визнач і закрий її, потім повтори setup; не заверши невідомі процеси навмання |
| Немає служби/завдання | Завдання видалили, шлях змінився, Python у карантині або встановлення перервалося | Перевір Захист Windows і останній журнал, потім запусти `setup.cmd` для ремонту |
| У Big Picture немає панелі | Steam не завантажив прапорець, SharedJSContext ще стартує або збірка Steam змінилася | Трохи зачекай, перевір status/log, перезапусти Steam; додай версію Steam до звіту |
| Панель є, фактів сейва немає | Гра/слот не підтримується, шлях інший або сейва немає | Звір список читачів; Continue? не вигадує факти й не записує сейви |
| Немає опису/трейлера/HLTB | Немає мережі, збій Store, згоди/налаштування, мало місця або немає необов'язкового `ffmpeg` | Статична картка має працювати; спробуй пізніше й перевір стан медіа |
| Помилка Python/hash/signature | Перехоплення мережі, неповне завантаження або карантин антивірусу | Не обходь перевірку; повтори у звичайній мережі й перевір Захист Windows |
| SmartScreen/антівірус попереджає | Скрипти альфи не підписані; вбудований Python підписаний python.org | Переглянь відкритий код і checksum. Не вимикай захист повністю й не запускай від адміністратора |
| Uninstall говорить про чуже завдання | Завдання з тим самим ім'ям не відповідає `install.json` | Збережи його; відновлюй маніфест або видаляй стороннє завдання лише після ідентифікації |
