# Первое использование Continue? на ПК

Открой Big Picture → главное меню Steam → **Continue?**. Этот же пункт доступен кнопкой **…** на странице игры. Внутри находятся общие настройки; отдельный выбор игры есть в разделе «Карточка игры».

**Без аккаунтов и ключей** работают карточки, поддерживаемые данные локальных сейвов, достижения Steam и исходные игровые иконки. Поддержка сейвов зависит от игры: если достоверных данных нет, Continue? их не придумывает. Новые сейвы появляются после сохранения в игре и обновления её страницы.

**Музыка:** зайди в «Музыка» → «Включить автоматическую музыку». Перед подтверждением показано, что будет загружено. При первом использовании понадобятся инструменты обработки, около 219 MB плюс yt-dlp, затем сам трек. После настройки тема подбирается при открытии игры. Включать каждую игру вручную не нужно. В этом разделе выбираются места воспроизведения и громкость. Кнопка ноты на странице игры позволяет заменить трек или выбрать «Без музыки» только для этой игры. Поиск использует YouTube, аккаунт YouTube не нужен. Если трек недоступен, появится состояние ошибки и возможность повторить попытку. Во время запущенной игры музыка оболочки и загрузки приостанавливаются.

**Фоны:** Steam — первый источник. Подготовка идёт только для открываемых игр, а не для всей библиотеки. Пока видео готовится или подходящего ролика нет, видна картинка. В разделе «Фоны» есть отдельный выключатель главной, предел качества 720p / 1080p / 4K и место для кэша 2 / 4 / 8 / 16 GB. Предел качества не повышает разрешение исходника: Steam часто даёт до 1080p; 4K зависит от конкретного источника и загрузчика. Поиск недостающих фонов на YouTube включается отдельно, после согласия. Кэш общий для фонов и музыки; старые файлы удаляются при необходимости, сейвы и игры не затрагиваются.

**Карточка игры:** «Все игры» задаёт общие параметры, «Эта игра» — исключения для открытой игры. Можно скрыть сюжетное место, описание, данные сейва, персонажей, достижения и время. Ниже перечислены именно доступные детали текущего сейва: например, тотемы и улики можно выключать независимо. «Как в общих настройках» снимает исключения этой игры. Сейв при этом не меняется.

**Картинки:** подключение SteamGridDB необязательно. В «Подключения» есть ссылка на страницу API. Создай аккаунт SteamGridDB, открой [страницу API](https://www.steamgriddb.com/profile/preferences/api), сгенерируй личный ключ и вставь его в окно картинок. Ключ хранится только в твоём профиле Continue?. После этого можно выбрать обложку, фон, логотип или широкую картинку; «Вернуть стандартную» восстанавливает исходную.

**Язык:** описания запрашиваются у Steam на языке твоего Steam. Если перевода нет, оригинал помечен. Google-аккаунт для этого не нужен; вход через Google и AI-перевод в этой публичной альфе не подключены.

**Оформление** сохраняет стиль Big Picture и даёт нужные переключатели. Дополнительные темы спрятаны в «Больше настроек оформления». Изменения применяются сразу; B / Esc закрывает окно.

**Статус:** публичная альфа (`continue-pc-0.1.4-r19.zip`), выпущена в релизе v0.1.4. Проверено на Windows 11 x64 на компьютере владельца. Windows 10, ARM64 и чистая система без Python — экспериментально, ждём отзывы. См. [инструкцию для ПК](install-pc.ru.md) и [быструю установку](quick-install.ru.md).
