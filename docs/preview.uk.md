# Запуск вітрини Continue?

[English](preview.md) · **Українська** · [Русский](preview.ru.md)

Поточний клон — статична презентація у браузері: 20 знімків збережень і вигляди Дек / ПК.
Він не підключається до Steam, не читає твої сейви, не встановлює плагін і не запускає ігри.

## Запуск

Потрібні Git-доступ до репозиторію, Python 3 і сучасний браузер. Репозиторій поки приватний,
тому для клонування потрібен акаунт із доступом. Залежності pip/npm та API-ключі не потрібні.

```sh
git clone https://github.com/Alexsander720/continue.git
cd continue
python tools/preview.py
```

Відкрий **http://127.0.0.1:8811/**. На Windows також працює `py -3 tools/preview.py`,
на macOS/Linux — `python3 tools/preview.py`. Зупинка: **Ctrl+C** у цьому терміналі.
Сервер доступний лише з поточного комп'ютера.

Якщо порт зайнятий: `python tools/preview.py --port 8813`, потім **http://127.0.0.1:8813/**.
Скрипт можна запускати з будь-якої папки, вказавши його абсолютний шлях.

## Керування

| Елемент | Результат |
|---|---|
| Обкладинки / назад-вперед | Вибір знімка збереження |
| Дек / ПК | Зміна розкладки пристрою |
| EN / UK / RU | Мова інтерфейсу; недоступні назви залишаються підписаною мовою джерела |
| Збільшення | Те саме демо в діалозі; Escape закриває й повертає фокус |
| Пауза тла | Зупинка рухомого тла |
| Пошук і фільтри каталогу | Пошук гри; три парсери, що перевіряються, показують лише підтверджену частину |
| Тур | MP4 на 40 секунд поточною мовою інтерфейсу |
| «Грати» / «Продовжити» | Демонстраційний відгук; гра не запускається |

У браузері передбачена розкладка контролера, але підтримку браузера/геймпада й фізичний пристрій потрібно
перевіряти окремо. Доступні клавіатура й сенсорне керування. Налаштування зменшення анімації враховується, де підтримується.

## Медіа та неполадки

| Що видно | Причина / дія |
|---|---|
| Немає кнопки музики | Теми навмисно виключені з Git; без локального файлу кнопка прихована |
| Інший сервер не дає перемотувати тур | Використовуй `tools/preview.py`: він підтримує діапазони HTTP і маршрути до `docs/img/` |
| Назви залишаються російськими/англійськими | Підписана мова перевіреного джерела; переклад інтерфейсу не вигадує рядків гри |
| ENSLAVED не має демо | Парсер перевіряється; підтверджений приклад не доданий |
| Сторінка не відкривається | Термінал сервера має працювати; перевір надрукований URL і порт |
| Змін не видно | Онови сторінку; перевір консоль/мережу на відсутній ресурс |

Тури зберігаються однією копією в `docs/img/tour-<lang>.mp4`. Сервер спрямовує `/media/tour-<lang>.mp4`
до неї без копіювання. Workflow Pages копіює відео в артефакт публікації.
Особисті сейви, таблиці імен і музика тем не входять у клон Git.

## Розробка та публікація

Змінюй `site/index.html`, `site/style.css`, `site/app.js`, `site/data.js` або `site/store.js` та оновлюй браузер.
Збірки немає. Перевіряй мови, розкладку, фокус і джерела; докладніше — [CONTRIBUTING](../CONTRIBUTING.md).

Workflow Pages публікує лише з публічного репозиторію. Зміна приватності, ввімкнення Pages і перевірене
посилання на сайт — окремі рішення власника. Локальний запуск нічого не публікує.
