# Быстрая установка: Steam Deck и Windows ПК

[English](quick-install.md) · [Українська](quick-install.uk.md) · **Русский**

### Steam Deck (4 шага)

1. Скачай [`continue-deck-0.1.4.zip`](https://github.com/Alexsander720/continue/releases/download/v0.1.4/continue-deck-0.1.4.zip) из [релиза v0.1.4](https://github.com/Alexsander720/continue/releases/latest) (распаковывать не нужно).
2. Нажми кнопку `…` на Steam Deck и перейди в **Decky → Настройки → Разработчик → Установить из URL/ZIP**.
3. Выбери скачанный ZIP-архив и подтверди установку.
4. Открой страницу любой поддерживаемой игры в библиотеке — Continue? уже работает!

Полная инструкция: [install-deck.ru.md](install-deck.ru.md).

### Windows ПК / Big Picture (5 шагов)

1. Убедись, что установлен Python 3.10+, и скачай [`continue-pc-0.1.4-r19.zip`](https://github.com/Alexsander720/continue/releases/download/v0.1.4/continue-pc-0.1.4-r19.zip) и `.sha256` из [релиза v0.1.4](https://github.com/Alexsander720/continue/releases/latest).
2. Распакуй ZIP-архив в любую обычную папку на компьютере.
3. Закрой запущенные игры и запусти `Continue\setup.cmd` (или `setup.cmd`) двойным кликом.
4. Согласись на включение локального отладочного порта Steam (`127.0.0.1:8080`) и подтверди перезапуск Steam.
5. Запусти Steam в режиме Big Picture и открой страницу любой поддерживаемой игры!

Полная инструкция: [install-pc.ru.md](install-pc.ru.md).
