# Швидке встановлення: Steam Deck та Windows ПК

[English](quick-install.md) · **Українська** · [Русский](quick-install.ru.md)

### Steam Deck (4 кроки)

1. Завантаж [`continue-deck-0.1.4.zip`](https://github.com/Alexsander720/continue/releases/download/v0.1.4/continue-deck-0.1.4.zip) з [релізу v0.1.4](https://github.com/Alexsander720/continue/releases/latest) (розпаковувати не потрібно).
2. Натисни кнопку `…` на Steam Deck і перейди в **Decky → Налаштування → Розробник → Встановити з URL/ZIP**.
3. Обери завантажений ZIP-архів і підтвердь встановлення.
4. Відкрий сторінку будь-якої підтримуваної гри в бібліотеці — Continue? уже працює!

Повна інструкція: [install-deck.uk.md](install-deck.uk.md).

### Windows ПК / Big Picture (5 кроків)

1. Переконайся, що встановлено Python 3.10+, та завантаж [`continue-pc-0.1.4-r19.zip`](https://github.com/Alexsander720/continue/releases/download/v0.1.4/continue-pc-0.1.4-r19.zip) і `.sha256` з [релізу v0.1.4](https://github.com/Alexsander720/continue/releases/latest).
2. Розпакуй ZIP-архів у будь-яку звичайну папку на комп'ютері.
3. Закрий запущені ігри та запусти `Continue\setup.cmd` (або `setup.cmd`) подвійним кліком.
4. Погодься на увімкнення локального налагоджувального порту Steam (`127.0.0.1:8080`) і підтвердь перезапуск Steam.
5. Запусти Steam у режимі Big Picture та відкрий сторінку будь-якої підтримуваної гри!

Повна інструкція: [install-pc.uk.md](install-pc.uk.md).
