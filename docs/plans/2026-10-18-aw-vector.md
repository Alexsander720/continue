# Alan Wake vector flashlight implementation plan

**Goal:** Replace only Alan Wake's raster rail with a static vector flashlight and expanding warm beam, preserving r5 layout and a tested return to r5.

**Architecture:** Keep the existing image element, intrinsic 48×768 dimensions, `object-fit: contain`, and `fitPanel` unchanged. Deliver one identical authored SVG to PC and Deck; reuse the shared bounded SVG validator from the optional public owner-theme service. Retain the unused PNG for source preservation and r5 comparisons.

**Tech Stack:** SVG paths and linear/radial gradients, Python standard library, existing Steam CEF and Chromium regression tests.

## Design decision

Use a narrow upward cone with a metal flashlight body at its base. Keep the established `#eee0b9` accent, warm amber stops, and a dark transparent background. Four static dust points add a little texture. No SVG filters, raster embeds, scripts, external references, animation, new frame callbacks, or renderer changes.

CSS pseudo-elements would require matching implementations in the shared renderer and live compatibility decorator. Inline SVG DOM would add lifecycle and cleanup code. An SVG image reuses both r5 image lifecycles and intrinsic aspect fitting.

## Execution and acceptance

1. Record installed r5 bytes, private source hashes, tasks, PID, no-running-game gate, and three native before fixtures.
2. Add a failing regression for the raster reference and absent SVG loader. Preserve existing files as `.bak-r6` before editing.
3. Add the bounded static SVG loader, shared owner-theme use, identical assets, and only Alan Wake's manifest change. Exclude local backups from packages.
4. Run the old PC/Deck tests and stdlib suite, measure actual geometry at four viewports and three text/logo cases, and compare native/isolated frame costs.
5. Build local r6 PC/Deck ZIPs, validate SHA256, CRC, markers, changed members, and private scan.
6. Upgrade using the standard installer in existing owner-theme mode after tests pass. Capture three native fixtures and four actual games, restore r5 using one command, verify live PNG and exact package bytes, then reinstall the same r6.
7. Independently read back the final installation and private state; run Orchestra structural checking followed by the requested real codex-pool review. Do not commit, push, publish, launch games, restart Steam, or contact the Deck.
