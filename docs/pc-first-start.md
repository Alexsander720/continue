# First use on PC

Open Big Picture → Steam main menu → **Continue?**, or **…** on a game page. Library, Game card, Backgrounds, Music, Appearance and Connections contain the global settings.

Cards, supported local saves, Steam achievements and authored game icons work without accounts. Missing save facts are never invented. Open a game after saving to refresh its progress.

In **Music**, choose **Enable automatic music** and review the download permission. First setup downloads the processing tools (about 219 MB plus yt-dlp), then theme tracks. Music is selected automatically for games you open. Choose playback locations and volume once; the note button changes a particular track or disables music for that game. YouTube search needs no YouTube account. Downloads and shell audio pause while playing a game.

**Backgrounds** uses Steam first and prepares only games you open. A still image remains while a video prepares or when none is available. Set Home playback, quality ceiling (720p / 1080p / 4K) and shared media cache (2 / 4 / 8 / 16 GB). A ceiling cannot improve the source: Steam often supplies up to 1080p; 4K depends on the source and downloader. YouTube fallback needs separate permission. Older cached media is removed as needed; games and saves are untouched.

In **Game card**, **All games** sets defaults; **This game** adds overrides. Hide story, description, save facts, characters, achievements and playtime independently. The individual details come from the current save, such as totems and clues. **Use global settings** removes that game's overrides without changing its save.

**Connections** explains optional SteamGridDB artwork setup: create an account, open the [API page](https://www.steamgriddb.com/profile/preferences/api), generate a personal key, paste it in the artwork picker. The key stays in your own Continue? profile. Restore default artwork with the picker button.

Descriptions use your Steam language. An untranslated original is marked. No Google account is needed; Google sign-in and AI translation are not connected in this public alpha.

**Appearance** keeps the existing Big Picture style. Detailed themes are under **More appearance options**. Changes apply immediately; B / Esc closes settings.

**Status:** local alpha test candidate; not published. Tested on Windows 11 x64. Windows 10, ARM64, and a clean system without Python are experimental — feedback is welcome. See [Windows installation](install-pc.md).
