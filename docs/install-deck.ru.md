# Установка публичной альфы на Steam Deck

[English](install-deck.md) · [Українська](install-deck.uk.md) · **Русский**

> Это альфа для тестеров, а не релиз в магазине Decky. Windows и Steam Big Picture — позже.

## Перед установкой

- Установи актуальный Decky Loader по его официальной инструкции.
- Скачай `continue-deck-<версия>.zip` из [последнего релиза](https://github.com/Alexsander720/continue/releases/latest). Вместо `<версия>` в имени файла будет номер с этой страницы. Не распаковывай архив.
- В релизе также есть `continue-deck-<версия>.zip.sha256`. При обновлении Continue? передаёт Decky тот же SHA-256; релиз без совпадающей контрольной суммы не предлагается.
- Если хочешь проверять чтение, оставь сохранение поддерживаемой игры локально. Continue? только читает его.

## Установка из ZIP

1. Перейди в игровой режим и открой Decky через меню быстрого доступа (`…`).
2. Открой **Decky → Настройки → Разработчик**.
3. Выбери **Установить из ZIP**, укажи `continue-deck-<версия>.zip` и подтверди.
4. Дождись Decky. В списке плагинов проверь, что у **Continue** указана версия скачанного ZIP (Decky не принимает «?» в имени плагина, поэтому в его списке «Continue»; сам плагин называется «Continue?»).
5. Открой страницу игры. В меню `…` Continue? выбери настройки интерфейса, источник фона, пресет, лимит кэша и полосу яркости.

Если твоя версия Decky показывает одну команду **Установить из URL/ZIP**, открой её и выбери вариант ZIP.

## Установка по URL

1. На странице релиза скопируй прямую ссылку на файл `continue-deck-<версия>.zip`, а не адрес страницы.
2. Открой **Decky → Настройки → Разработчик → Установить из URL/ZIP**.
3. Вставь прямую HTTPS-ссылку на ZIP, подтверди и дождись Decky.
4. Проверь, что у **Continue** в списке плагинов указана версия скачанного ZIP, и открой страницу игры.

Не вставляй ссылку на ветку/исходники или на файл `.sha256` в поле ZIP.

## Выбор при первом запуске

- **Источник фона:** по умолчанию Steam. YouTube и музыка темы включаются двумя отдельными диалогами согласия; отказ оставляет их выключенными. Steam Game Recording работает локально, только если есть подходящая запись.
- **Пресет:** по умолчанию «Лёгкий». «Лёгкий» и «Сбалансированный» ограничивают видео 720p, «Максимум» — 1080p. «Лёгкий» отключает видео на главной и оставляет статичный фон от батареи. «Максимум» разрешает видео везде.
- **Кэш:** 1, 2, 4 или 8 ГБ выбираются отдельно от пресета. Старые фоны вытесняются в рамках лимита.
- **Вкладки библиотеки:** включи **Вкладки Continue?** в настройках плагина и открой библиотеку заново. **Установлено** показывает игры на этой Деке, **С ПК** — на других подключённых клиентах Steam. По умолчанию переключатель выключен; при наличии TabMaster вкладки Continue? не включаются.
- **Язык:** интерфейс следует языку Steam и поддерживает английский, украинский и русский. Текст игры зависит от доказанных строк в её файлах.
- **Яркость:** полосу Continue? можно выключить. Если активен отдельный Brightness Bar, Continue? не рисует дубль.

## Обновления

Continue? не чаще раза в сутки проверяет GitHub Releases и предлагает обновление только при наличии ZIP и его SHA-256. Установку выполняет Decky; плагин не перезаписывает себя. После обновления Decky может не закрыть окно с прогрессом и не показать новую версию сразу — закрой окно и один раз перезапусти клиент Steam (или перезагрузи Деку). При ошибке проверки установленная версия продолжает работать, а повторить проверку можно из строки версии.

## Если не установилось

1. Убедись, что Decky открывается и есть раздел **Настройки → Разработчик**.
2. Скачай ZIP заново; не переименовывай, не распаковывай и не перепаковывай его.
3. При установке по URL проверь, что ссылка начинается с `https://` и ведёт прямо на `.zip`.
4. Один раз перезапусти клиент Steam и повтори установку через Decky.
5. Если Continue? появился, но экран неполный, выбери **«Собрать отчёт для разработчика»** в его меню `…`. Проверь обезличенный JSON, сохрани ZIP и следуй [памятке тестера](alpha-testers.ru.md).

Не прикладывай сейвы, личные логи Steam и скриншоты с данными аккаунта, если разработчик отдельно не попросил обезличенный пример.

## Удаление

1. Открой Decky через меню быстрого доступа.
2. В управлении плагинами/настройках Decky выбери **Continue?** и **Удалить**.
3. Подтверди и дождись удаления. Если старая панель осталась, перезапусти клиент Steam.

Удаление не должно менять сохранения и файлы игр. Нужный диагностический отчёт собери до удаления.

## Настройка музыки

Открой Continue? в меню Decky → **Музыка** → **Включить автоматическую музыку**. Первая настройка ~180 МБ, около полуминуты; при заряде 30% и ниже подключи зарядку. Подтверди необязательную загрузку инструментов, затем отдельных тем. Всё хранится в данных Continue?; SteamOS и PATH не меняются. Темы готовятся для открываемых игр. Выбери громкость и места воспроизведения: главная или страница игры. Для открытой игры доступны «Автоматическая тема» и «Без музыки». После настройки аудио готовится и на батарее при заряде выше 15%; подготовка видео ждёт зарядки. Во время игры загрузки приостанавливаются. При ошибке есть «Попробовать ещё раз» и «Обновить загрузчик музыки»; проверенную прежнюю версию загрузчика можно вернуть. Это локальный кандидат 0.1.4; звук, контроллер и сон на настоящей Deck ещё требуют проверки.
